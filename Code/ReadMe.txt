I have included the Python library in our Git to make it portable so you can use it more easily.
See usage instructions below.

In order to import the Python API to your code:
    - The .py file must be in the Code folder
    - Use the line "from UnicornPython.Lib import UnicornPy"

If you want to put your .py file into a different folder (or if this doesn't work for you),
you can follow the "Set Library Path" instructions instead, and then use "import UnicornPy" without the "from" statement:
https://github.com/unicorn-bi/Unicorn-Hybrid-Black-Windows-APIs/blob/main/python-api/unicorn-python-api.md#Set-library-path
